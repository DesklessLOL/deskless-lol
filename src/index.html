Solana-native idea

Put the rulebook inside the coin

Deskless is built on one idea: a coin should carry its own rulebook. Small programs called hooks wake up whenever it moves. They can skim a charge, burn a slice, update a ledger or veto the move outright. Nothing sits on the sidelines watching.

Plate B

What a rule can say

  • 01

    Skim

    Route a share of each move to an address the rule picks.

  • 02

    Burn

    Retire a slice of each send so supply thins as the coin gets used.

  • 03

    Price

    Fix what an exchange costs before it executes.

  • 04

    Remember

    Park a small note beside each balance, saved when the balance is.

  • 05

    Refuse

    Cancel everything. Nothing shifts, nobody pays.

Plate C

No night shift required

Plenty of coins fake their rules with a script on somebody’s server. That script holds keys, can stall, and answers to whoever pays the hosting bill. A rule inside the coin has none of those weak spots.

Outside

A script beside the coin

  • Lives on a private machine
  • Holds wallet keys to act
  • Stops the moment the server does
  • Trust means trusting the operator

Inside

A rule in the coin

  • Lives on the ledger beside every balance
  • Fires on its own with each move
  • Runs as long as the chain does
  • Trust means reading the code

Open design space

Rules nobody has written yet

Once the rulebook is code, the list of possible tokens gets long. A few sketches:

  • Loyalty curve

    Charges shrink the longer an address sits on its coins.

  • Sell-side burn

    Destroy a sliver only when an exchange leaves the pool.

  • Holder perks

    Discounts for wallets that also hold a partner token.

  • Cooling brake

    Lift charges briefly after a violent price swing.

  • Referral share

    Send a slice to whoever brought the buyer.

  • Time-weighted drops

    Reward by how long balances sat, not by how big they were.
